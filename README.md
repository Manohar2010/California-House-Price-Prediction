# California Housing Price Prediction
# Project Overview

This project uses Machine Learning to predict California housing prices using the California Housing dataset from scikit-learn.

A Linear Regression model was trained using a preprocessing pipeline that includes feature scaling with StandardScaler.

# Dataset

The dataset used in this project is the California Housing dataset available in Scikit-learn.

# Features include:

Median Income
House Age
Average Rooms
Average Bedrooms
Population
Average Occupancy
Latitude
Longitude

# Target:

Median House Value

# Technologies Used
Python
Pandas
Scikit-learn
